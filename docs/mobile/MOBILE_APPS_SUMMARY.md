## Troubleshooting Quick Reference

### Common Issues

**"Unable to reach server"**
- Check server URL spelling
- Verify HTTPS certificate
- Test URL in browser

**Auto-fill not working (iOS)**
- Settings → Passwords → Select Bitwarden
- Disable other password managers
- Restart iPhone

**Auto-fill not working (Android)**
- Settings → Autofill service → Select Bitwarden
- Grant all permissions
- Disable battery optimization

**See full troubleshooting:** [Setup Guide](MOBILE_SETUP_GUIDE.md#troubleshooting)
